# Claude Focus Board

A cozy, single-user focus board: a relaxing background with small Apps you can drag and resize.

## Run it on your computer
You need [Node.js](https://nodejs.org) (LTS version) and Git.

```bash
git clone https://github.com/KNorton1531/ClaudeFocusBoard.git
cd ClaudeFocusBoard
npm install
npm run dev
```

Then open the link it prints (usually http://localhost:5173/ClaudeFocusBoard/).
