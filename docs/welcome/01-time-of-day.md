# Time of Day (Header)

Hour by hour, like the old version. Each hour has 2 or 3 lines; one is picked per day so it doesn't repeat every day.
`{name}` is optional in every line (off if no name set).

## Hourly lines
- 12am - "It's the midnight hour, {name}." / "Midnight. The house is quiet."
- 1am - "The early hours. Peaceful, isn't it?" / "You're up late, {name}."
- 2am - "Still up, {name}?" / "Deep in the night now."
- 3am - "It's the dead of night, {name}." / "Even the owls are sleepy."
- 4am - "Quiet before sunrise. Everything is still." / "Nearly morning, {name}."
- 5am - "The sun will be up soon, {name}." / "Early start today."
- 6am - "Dawn's breaking, {name}." / "First light."
- 7am - "Good morning, {name}. The day is starting." / "Morning, {name}. Coffee first."
- 8am - "Time to get going, {name}." / "Morning, {name}. Let's ease into it."
- 9am - "Good morning, {name}." / "Fresh start, {name}."
- 10am - "Morning's in full swing, {name}." / "Settling in nicely."
- 11am - "Morning, {name}. Almost time for a break." / "Nearly lunchtime."
- 12pm - "Time for some lunch, {name}?" / "Midday already."
- 1pm - "Afternoon, {name}. Well into the day." / "Back at it, {name}."
- 2pm - "A good time for a short break, {name}." / "Afternoon slump? Stretch it out."
- 3pm - "Afternoon, {name}." / "Tea time, {name}?"
- 4pm - "Almost time to relax, {name}." / "Home stretch."
- 5pm - "Evening, {name}." / "Day's winding down."
- 6pm - "Evening, {name}. How's your day gone?" / "Time to switch off."
- 7pm - "Perfect time for a chill out, {name}." / "Settle in, {name}."
- 8pm - "Cozy evening, {name}." / "Feet up time."
- 9pm - "It's getting late, {name}." / "Night's drawing in."
- 10pm - "Late evening. Time to start winding down." / "Nearly bedtime, {name}."
- 11pm - "Evening, {name}. Time for reflection or rest." / "One more thing, then bed?"

## Short greetings (used when another category supplies the line)
When a holiday or season takes the header, the hour still gives a short opener:
- 12am to 4am - "You're up late, {name}."
- 5am to 11am - "Morning, {name}."
- 12pm to 4pm - "Afternoon, {name}."
- 5pm to 11pm - "Evening, {name}."

Example: "Morning, {name}. It's the first day of Winter."
