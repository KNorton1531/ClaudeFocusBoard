# Build Roadmap

Each step ends with something working and live on GitHub Pages. Small steps, so it never stalls.

1. **Setup** - Vite + React project, folder structure, deploy to GitHub Pages. Live page says "Hello".
2. **Board + background** - One placeholder background (Autumn forest) filling the screen, theme CSS variables.
3. **Welcome message** - Top left, using the logic in welcome/10-logic.md.
4. **App frame + drag/resize** - Shared AppFrame, react-grid-layout, layout saved via storage.js.
5. **First apps** - Clock, then Pomodoro.
6. **Settings panel** - Background, theme, name, Auto / Manual / Off modes, export / import.
7. **Audio apps** - Ambient mixer, Lofi radio, YouTube livestream, Spotify.
8. **Weather + effects** - Weather app, rain and snow effects.
9. **All backgrounds** - Night city and Cabin in the snow, scene animations, swap in AI art.
10. **Sticky notes** and polish.
