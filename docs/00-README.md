# Focus Board: Planning Docs

These files are the source of truth for the project. Start any new chat by pointing Claude here.

| File | What it holds |
|---|---|
| 01-project-description.md | What we're building and why |
| 02-tech-stack.md | Tools and how the pieces fit |
| 03-backgrounds.md | Background ideas (pick your starters) |
| 04-apps.md | App ideas (pick your starters) |
| 05-themes.md | Themes, seasons, time of day |
| welcome/ | Welcome message plan, one file per category (start with 00-overview.md) |
| 07-style-sheet.md | Colors, fonts, spacing, code style rules |
| 08-roadmap.md | Build order, step by step |

Status tags used in lists: `[v1]` = build first, `[later]` = someday, `[?]` = undecided.
